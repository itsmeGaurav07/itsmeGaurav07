## `01` / Engineering Identity

<img align="right" width="145" src="https://media.giphy.com/media/3o7qE1YN7aBOFPRw8E/giphy.gif" alt="Animated space atmosphere"/>

I'm an Electronics and Communication Engineering undergraduate exploring the engineering behind digital hardware, programmable logic, and intelligent systems.

My focus is on understanding how hardware is designed, simulated, verified, and implemented — from individual logic blocks to complete FPGA-based systems.

- **Hardware design:** Verilog HDL, RTL design, finite state machines.
- **FPGA engineering:** Digital architectures and hardware-accelerated processing.
- **Verification:** RTL simulation, testbenches, and functional correctness.
- **Intelligent systems:** Embedded computing and computer vision.
- **Current learning:** SystemVerilog, design verification, and computer architecture.
